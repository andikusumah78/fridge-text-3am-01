One line a smart fridge texts its owner at 3am: a deadpan appliance calling out the fourth snack-raid visit of the night. Entry for make.fun's "The 3AM Fridge Text" bounty ($2 in USDC, winner takes all).

The line (130 characters):

> 3am. You opened me for the fourth time tonight, took nothing, and closed me like we never met. I am a fridge, not a situationship.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Pure Python 3 standard library, deterministic, no network.
